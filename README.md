selenium-java-automation-practice
Comprehensive practice repository for Selenium WebDriver with Java, covering UI automation, synchronization (Implicit/Explicit waits), dynamic element handling, and advanced framework development with TestNG and Maven. Java Selenium Automation Practice
This repository contains my progress and automation scripts as I master Selenium WebDriver with Java. The goal is to build a solid foundation in web automation, progressing from basic element interaction to designing robust industry-standard frameworks.

🛠 Technologies & Tools
Language: Java (JDK 11+)
Automation Tool: Selenium WebDriver 4.0
Build Tool: Maven
Test Runner: TestNG
IDE: IntelliJ IDEA
🚀 Key Learning Milestones
 Locators: Mastering XPath, CSS Selectors, and dynamic element handling.
 Synchronization: Implementing Implicit and Explicit (WebDriverWait) waits.
 Interactions: Handling Auto-suggestive dropdowns, Checkboxes, and Radio buttons.
 Advanced UI: Managing Ajax calls, Child Windows, Frames, and Mouse Actions.
 Framework Design: (Planned) Page Object Model (POM) and Data-Driven testing.
📝 Practice Exercises
Passenger Picker: Automated dynamic passenger selection on practice flight portals.
Alert Handling: Logic to handle JavaScript alerts and confirmations.
E-commerce: End-to-end flow for adding items to a cart.
